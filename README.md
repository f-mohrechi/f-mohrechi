# Hi, I'm Mahi Mohrechi 👋

**Frontend engineer** building production web applications with React, Next.js and TypeScript.

I work on a cryptocurrency exchange frontend at Bitmax, where I independently migrated server-state management from Redux Saga to TanStack React Query across more than 25 routes of a Next.js application. I have also built localized marketing sites for DanaCloud and DanaIX.

Most of my professional work lives in private repositories, so my public repos here are mostly side projects from earlier in my career.

## What I work on

- Data-fetching architecture with TanStack React Query
- Authentication and token-refresh flows with Axios
- Internationalization with next-intl
- Turning Figma designs into maintainable Next.js and Tailwind CSS
